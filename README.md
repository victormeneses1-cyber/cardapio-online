# 🍔 Cardápio Online - Arena São Francisco

Projeto de um cardápio digital interativo desenvolvido com HTML, CSS e JavaScript.

O objetivo é facilitar o atendimento na arena, permitindo que o cliente monte seu pedido e envie diretamente via WhatsApp.

---

## 🚀 Funcionalidades

- 📋 Menu lateral com categorias
- 🍕 Pizzas com descrição
- 🍢 Espetinhos com acompanhamento
- 🥤 Bebidas e cervejas
- 🍟 Porções
- 🛒 Carrinho de pedidos fixo
- 👤 Identificação do cliente
- 📲 Envio automático para WhatsApp
- 💻 Layout organizado e responsivo

---

## 🧠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
